Move `@credo-ts/hedera` into Credo Extensions while retaining its npm package name and public entry points. This release
keeps Hedera DID and AnonCreds support, including the dedicated `/anoncreds` entry point, optional AnonCreds peers,
second-based revocation timestamps, same-second status-list resolution, and signing with the expected public key.
